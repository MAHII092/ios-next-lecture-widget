\# 🎓 Next Lecture Widget



A clean and minimal \*\*iPhone lecture timetable widget\*\* built with \*\*Scriptable\*\*.



The widget automatically checks the current day and time and displays the upcoming college lecture along with its scheduled time and classroom



\## ✨ Features



\- Displays the next lecture

\- Shows lecture start and end time

\- Shows classroom / room number

\- Monday to Friday timetable

\- Designed for iPhone

\- Runs using Scriptable
