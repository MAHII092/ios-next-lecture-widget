\# 🎓 Next Lecture Widget



A clean and minimal \*\*iPhone lecture timetable widget\*\* built with \*\*Scriptable\*\*.



The widget automatically checks the current day and time and displays the upcoming college lecture along with its scheduled time and classroom



\## ✨ Features



\- Displays the next lecture

\- Shows lecture start and end time

\- Shows classroom / room number

\- Monday to Friday timetable

\- Designed for iPhone

\- Runs using Scriptable

🚀 Installation
1. Install Scriptable

Download Scriptable from the App Store.

2. Create a new script

Open Scriptable and create a new script named:

Next Lecture
3. Copy the code

Open NextLecture.js from this repository.

Copy the complete code.

Paste it into the Scriptable script.

4. Run the script

Run the script once inside Scriptable.

The widget preview should appear.

5. Add the widget

On the iPhone Home Screen:

Long press on an empty area.
Tap +.
Search for Scriptable.
Select a rectangular widget.
Add the widget.
Long press the widget.
Select Edit Widget.
Choose the Next Lecture script.
